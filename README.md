TECHQUEST🚀
An interactive tech quiz game built with HTML, CSS and JavaScript.

Test your tech knowledge, challenge yourself against the timer, and see how well you perform!

✨Features
● 10 interactive quiz questions.
● 20-second countdown timer.
● Instant correct and incorrect answer feedback.
● Dynamic score tracking and progress bar.
● Sound effects using web Audio API.
● Results screen with performance badges.
● Answer review section.
● Retry and home options.
● Responsive design for mobile, tablet and desktop.

🛠️Technologies Used
● HTML5
● CSS3
● JavaScript
● Web Audio API

🏃‍♂️How to Run
1. Download or clone this repository.
2. Open the project folder.
3. Open index.html in your browser.
4. Click Start and enjoy the quiz.
